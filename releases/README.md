# Installable Android build

`German-C1-App-debug.apk` is the current debug-signed Android build for personal testing.

## Install

1. Download the APK to an Android phone.
2. Open it in the phone's Files/Downloads app.
3. If Android asks, allow that app to install unknown apps, then choose **Install**.
4. If Android reports a conflicting signature, uninstall the older app first, then install this build.

This is not a Play Store release. It is signed with the project's debug key and is intended for direct personal installation. Each future completed change should rebuild and replace this APK at the same path.
